## 🔄 分层架构详解

### 1. APIs Layer (internal/apis/)
**职责**: 处理HTTP请求/响应、参数验证、认证授权

**核心组件**:
- `handlers/`: HTTP处理器实现
- `middlewares/`: 横切关注点（认证、日志、限流等）
- `routes/`: 路由定义和注册
- `validators/`: 请求参数验证

**设计原则**:
- ✅ 使用中间件处理跨切面关注点
- ✅ 输入验证和错误处理
- ✅ 调用 business/services 层处理业务
- ❌ 禁止包含业务逻辑
- ❌ 禁止直接访问数据库

### 2. Business Layer (internal/business/)
**职责**: 核心业务逻辑、领域规则、工作流编排

**核心组件**:
- `domains/`: 领域实体和值对象
- `services/`: 业务服务（协调多个领域对象）
- `workflows/`: 复杂业务流程
- `policies/`: 业务规则和策略

**设计原则**:
- ✅ 通过接口抽象外部依赖
- ✅ 返回领域特定的错误类型
- ✅ 实现核心业务规则
- ❌ 禁止依赖具体技术实现
- ❌ 禁止包含基础设施代码

### 3. Infrastructure Layer (internal/infrastructure/)
**职责**: 技术细节实现、第三方服务集成

**核心组件**:
- `config/`: 配置加载和管理
- `security/`: 认证、授权、加密
- `events/`: 事件发布/订阅
- `context/`: 上下文扩展和管理

**设计原则**:
- ✅ 实现 business 层定义的接口
- ✅ 处理技术异常并转换为业务异常
- ✅ 提供技术基础设施支持

### 4. Repositories & Models Layer
**职责**: 数据持久化操作和实体映射

**核心组件**:
- `repositories/`: 数据访问实现
- `models/`: 数据库实体映射

**设计原则**:
- ✅ 使用 GORM 进行数据库操作
- ✅ 实现 Repository 接口
- ✅ 数据库迁移管理
- ❌ 禁止包含业务逻辑

### 插件类型

- **Indexer Plugins**: 索引和搜索
- **MediaServer Plugins**: 媒体服务器集成
- **Notification Plugins**: 通知服务

## 📊 数据流架构

### 请求处理流程
```
1. HTTP Request → API Gateway
2. API Gateway → Authentication Middleware
3. Authentication → Handler
4. Handler → Business Service
5. Business Service → Repository
6. Repository → Database
7. Response ← Database ← Repository ← Business ← Handler ← Client
```

## 🔐 安全架构

### 认证授权
- **JWT Token**: 无状态认证
- **RBAC**: 基于角色的访问控制
- **API Key**: 第三方服务认证

### 数据安全
- **传输加密**: HTTPS/TLS
- **存储加密**: 敏感数据加密存储
- **审计日志**: 操作审计追踪

## 🚀 部署架构

### 容器化部署
```yaml
services:
  app:
    image: moviepilot-go:latest
    ports:
      - "3001:3001"
    depends_on:
      - postgres
      - redis
  
  postgres:
    image: postgres:14
    environment:
      POSTGRES_DB: moviepilot
  
  redis:
    image: redis:6-alpine
  
  plugins:
    image: moviepilot-plugins:latest
    ports:
      - "5000:5000"
```

### 高可用部署
- **负载均衡**: Nginx + 多实例
- **数据库**: PostgreSQL 主从复制
- **缓存**: Redis 集群
- **监控**: Prometheus + Grafana

## 📈 性能优化策略

### 并发处理
- **Goroutines**: 轻量级并发
- **Channels**: 协程间通信
- **Connection Pool**: 数据库连接池

### 缓存策略
- **多级缓存**: 内存 + Redis
- **缓存预热**: 系统启动预加载
- **缓存更新**: 主动 + 被动更新

### 数据库优化
- **索引优化**: 查询性能提升
- **分页查询**: 大数据集处理
- **读写分离**: 负载分担

## 🔄 扩展性设计

### 水平扩展
- **无状态设计**: 服务实例可任意扩展
- **负载均衡**: 请求分发

### 垂直扩展
- **模块化设计**: 功能模块独立
