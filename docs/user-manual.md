## 快速开始

### 首次登录

1. 访问 http://localhost:3001
2. 使用默认管理员账号登录
   - 用户名: `admin`
   - 密码: `admin123`
3. **重要**: 首次登录后请立即修改密码

### 基本配置流程

```
1. 修改管理员密码
   ↓
2. 配置下载器（qBittorrent/Transmission）
   ↓
3. 配置媒体服务器（Emby/Plex/Jellyfin）
   ↓
4. 添加 PT/BT 站点
   ↓
5. 创建订阅
   ↓
6. 开始自动化管理
```

## 用户管理

### 创建用户

1. 进入 **系统设置** → **用户管理**
2. 点击 **新建用户**
3. 填写用户信息：
   - 用户名（必填）
   - 密码（必填，至少 8 位）
   - 邮箱（可选）
   - 角色（管理员/普通用户）
4. 点击 **保存**

### 角色权限

| 角色 | 权限 |
|------|------|
| **管理员** | 所有权限 |
| **普通用户** | 查看订阅、下载、媒体库 |
| **访客** | 仅查看权限 |

### 修改密码

1. 点击右上角头像
2. 选择 **个人设置**
3. 在 **安全设置** 中修改密码
4. 输入旧密码和新密码
5. 点击 **保存**

## 站点管理

### 添加 PT/BT 站点

1. 进入 **站点管理** → **站点列表**
2. 点击 **添加站点**
3. 填写站点信息：
   - **站点名称**: 如"馒头"、"HDChina"
   - **站点地址**: 完整 URL
   - **Cookie**: 从浏览器复制
   - **User-Agent**: 浏览器 UA（可选）
4. 点击 **测试连接**
5. 测试成功后点击 **保存**

### Cookie 获取方法

**方法一：浏览器开发者工具**
1. 登录站点
2. 按 F12 打开开发者工具
3. 切换到 **Network** 标签
4. 刷新页面
5. 找到站点请求，复制 Cookie

**方法二：浏览器插件**
1. 安装 EditThisCookie 插件
2. 登录站点
3. 点击插件图标
4. 复制所有 Cookie

### 自动签到

1. 在站点列表中找到目标站点
2. 点击 **编辑**
3. 启用 **自动签到**
4. 设置签到时间（默认每天 8:00）
5. 点击 **保存**

### Cookie 自动同步

系统会每小时自动同步 Cookie，确保站点连接正常。

## 订阅管理

### 创建订阅

1. 进入 **订阅管理** → **我的订阅**
2. 点击 **新建订阅**
3. 搜索影视剧：
   - 输入名称或 TMDB ID
   - 选择正确的影视剧
4. 配置订阅：
   - **类型**: 电影/电视剧
   - **质量**: 1080p/4K/蓝光原盘
   - **季度**: 全部/指定季
   - **集数**: 全部/指定集
   - **站点**: 选择搜索站点
5. 点击 **创建订阅**

### 订阅状态

| 状态 | 说明 |
|------|------|
| **等待中** | 等待资源发布 |
| **搜索中** | 正在搜索资源 |
| **下载中** | 正在下载 |
| **已完成** | 订阅完成 |
| **失败** | 搜索或下载失败 |

### 订阅刷新

- **自动刷新**: 每 30 分钟自动检查更新
- **手动刷新**: 点击订阅卡片的 **刷新** 按钮

### 订阅分享

1. 在订阅列表中找到目标订阅
2. 点击 **分享** 按钮
3. 复制分享链接
4. 发送给其他用户

## 下载管理

### 配置下载器

**qBittorrent 配置**:
1. 进入 **系统设置** → **下载器**
2. 选择 **qBittorrent**
3. 填写配置：
   - 地址: `http://localhost:8080`
   - 用户名: `admin`
   - 密码: `adminadmin`
4. 点击 **测试连接**
5. 测试成功后点击 **保存**

**Transmission 配置**:
1. 选择 **Transmission**
2. 填写配置：
   - 地址: `http://localhost:9091`
   - 用户名: `transmission`
   - 密码: `transmission`
3. 测试并保存

### 下载任务管理

**查看任务**:
- 进入 **下载管理** → **任务列表**
- 查看所有下载任务状态

**任务操作**:
- **暂停**: 暂停下载
- **继续**: 恢复下载
- **删除**: 删除任务（可选删除文件）
- **优先级**: 调整下载优先级

### 下载监控

**实时监控**:
- 下载速度
- 上传速度
- 剩余时间
- 完成进度

**统计信息**:
- 总下载量
- 总上传量
- 分享率
- 活跃任务数

## 媒体库整理

### 配置媒体服务器

**Emby 配置**:
1. 进入 **系统设置** → **媒体服务器**
2. 选择 **Emby**
3. 填写配置：
   - 地址: `http://localhost:8096`
   - API Key: 从 Emby 设置中获取
4. 测试并保存

**Plex/Jellyfin 配置**:
- 类似 Emby 配置流程
- 填写对应的地址和 API Key

### 自动整理

**整理规则**:
1. 进入 **媒体库** → **整理设置**
2. 配置整理规则：
   - **电影目录**: `/media/movies`
   - **电视剧目录**: `/media/tv`
   - **命名格式**: 
     - 电影: `{title} ({year})`
     - 电视剧: `{title}/Season {season}/{title} S{season}E{episode}`
3. 启用 **自动整理**
4. 点击 **保存**

**整理流程**:
```
下载完成
   ↓
识别媒体信息（TMDB）
   ↓
重命名文件
   ↓
转移到媒体库
   ↓
通知媒体服务器刷新
```

### 手动整理

1. 进入 **媒体库** → **待整理**
2. 选择文件
3. 点击 **识别**
4. 确认信息
5. 点击 **整理**

## 插件系统

### 浏览插件

1. 进入 **插件中心** → **插件市场**
2. 浏览可用插件：
   - **站点插件**: PT/BT 站点支持
   - **索引器**: 资源搜索
   - **通知插件**: 消息推送
   - **下载器**: 下载客户端
   - **媒体服务器**: 媒体库管理

### 安装插件

1. 在插件市场中找到目标插件
2. 点击 **安装**
3. 等待安装完成
4. 配置插件参数
5. 启用插件

### 配置插件

1. 进入 **插件中心** → **已安装**
2. 找到目标插件
3. 点击 **设置**
4. 填写配置参数
5. 点击 **保存**

### 插件示例

**Telegram 通知插件**:
- Bot Token: 从 @BotFather 获取
- Chat ID: 从 @userinfobot 获取
- 通知类型: 订阅更新、下载完成、系统告警

**WeChat 企业微信插件**:
- Corp ID: 企业 ID
- Agent ID: 应用 ID
- Secret: 应用密钥

## 工作流

### 创建工作流

1. 进入 **工作流** → **我的工作流**
2. 点击 **新建工作流**
3. 配置工作流：
   - **名称**: 如"新剧自动下载"
   - **描述**: 工作流说明
   - **触发条件**: RSS 更新、定时任务等
4. 添加步骤：
   - 拖拽步骤到画布
   - 配置步骤参数
   - 连接步骤
5. 点击 **保存**

### 工作流步骤类型

| 类型 | 说明 | 示例 |
|------|------|------|
| **动作** | 执行操作 | 添加下载、发送通知 |
| **条件** | 判断分支 | 如果质量 >= 1080p |
| **循环** | 重复执行 | 遍历所有订阅 |
| **并行** | 同时执行 | 同时搜索多个站点 |
| **延迟** | 等待时间 | 等待 5 分钟 |
| **通知** | 发送消息 | Telegram 通知 |

### 工作流示例

**示例 1: 新剧自动下载**
```
RSS 更新触发
   ↓
检查是否已订阅
   ↓
搜索资源
   ↓
质量筛选（>= 1080p）
   ↓
添加下载
   ↓
发送 Telegram 通知
```

**示例 2: 下载完成自动整理**
```
下载完成触发
   ↓
识别媒体信息
   ↓
重命名文件
   ↓
转移到媒体库
   ↓
刷新媒体服务器
   ↓
发送完成通知
```

## 系统设置

### 基本设置

- **系统名称**: 自定义系统名称
- **时区**: 选择时区
- **语言**: 中文/英文

### 安全设置

- **JWT 过期时间**: Access Token 15 分钟
- **会话超时**: 7 天
- **密码策略**: 最少 8 位，包含字母和数字

### 通知设置

- **Telegram**: 配置 Bot Token 和 Chat ID
- **WeChat**: 配置企业微信
- **Email**: 配置 SMTP 服务器

### 性能设置

- **缓存**: 启用 Redis 缓存
- **并发数**: 最大并发下载数
- **刷新间隔**: 订阅刷新间隔

## 常见问题

### Q1: 无法登录

**原因**: 密码错误或账号被锁定

**解决**:
1. 检查用户名和密码
2. 等待 15 分钟后重试（账号锁定）
3. 联系管理员重置密码

### Q2: 站点连接失败

**原因**: Cookie 过期或站点地址错误

**解决**:
1. 重新获取 Cookie
2. 检查站点地址是否正确
3. 检查网络连接

### Q3: 订阅无法搜索到资源

**原因**: 站点没有资源或搜索条件过于严格

**解决**:
1. 放宽搜索条件（降低质量要求）
2. 添加更多站点
3. 检查站点是否正常

### Q4: 下载速度慢

**原因**: 种子无速度或网络限制

**解决**:
1. 检查种子健康度
2. 调整下载器设置
3. 检查网络带宽

### Q5: 文件整理失败

**原因**: 权限不足或目录不存在

**解决**:
1. 检查目录权限
2. 确保目录存在
3. 检查磁盘空间
